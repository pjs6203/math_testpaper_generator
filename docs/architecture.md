# 설계와 검수 범위

```mermaid
flowchart LR
    P[원본 PDF] --> R[prepare: 텍스트 + 모든 페이지 PNG]
    R --> A[작업 중인 AI: 전사 · 번역 · 원문 대조]
    A --> J[exam.json]
    J --> V[validate]
    V --> B[Python 조판 + 로컬 MathJax 벡터 수식]
    B --> O[exam.pdf + validation.json + PNG]
    O --> Q[AI의 전 페이지 시각 검수]
    Q --> F[review + verify --require-reviewed]
```

## 역할

`model.py`는 문항과 수식 구문, 문항 수, 총점, 자산 경로, 원문 해시와 대조 상태를 검사합니다. `source.py`는 PDF 추출·렌더링·벡터 crop을 담당합니다. `mathsvg.py`와 `_math.cjs`는 로컬 MathJax를 호출하고 SVG 경로를 PDF 벡터로 출력합니다. `layout.py`는 고정된 두 단에 한 문제씩 조판하고 그림 PDF를 병합합니다. `qa.py`는 PDF·문항 스냅샷·미리보기·검수 기록의 해시와 배치 계약을 확인합니다.

AI가 원문을 이해하는 역할은 이 코드에 포함하지 않습니다. 문항에 정답·해설·새 조건을 추측해 넣지 않도록 AGENTS.md가 작업 절차를 지정합니다. AI API나 외부 모델 호출이 없으므로 별도 계정 설정이 없습니다.

## 기본 좌표

| 항목 | PDF 포인트 |
| --- | --- |
| 종이 | 842 × 1191 (A3 세로에 해당하는 기준값) |
| 좌측 경계 / 우측 경계 | 87.9 / 754.02 |
| 중앙 구분선 | x = 420.96 |
| 왼쪽 / 오른쪽 문항 시작 | x = 87.9 / 434.4 |
| 본문 들여쓰기 / 너비 | 27 / 292 |
| 첫 면 본문 위 구분선 | y = 917.339 |
| 이후 면 본문 위 구분선 | y = 1063.499 |
| 아래 구분선 | y = 106.559 |
| 본문 / 수식 기본 크기 | 11.5 / 10.98 |

이는 사용자가 제공한 평가원 수학 시험지를 분석한 배치 기준입니다. 새 문항의 글리프와 줄바꿈이 공식 조판 결과와 완전히 같다는 주장은 하지 않습니다. 원본 평가원 PDF의 글꼴을 추출하여 재배포하지 않습니다.

## 자동으로 확인하는 내용

- 문항 수·순서·중복, 유형별 선택지 수, 총점
- 미완료 원문 대조 상태와 원본 PDF 변경
- 닫히지 않은 수식 구분자와 MathJax 오류
- 출력 수식 인스턴스의 누락·중복
- 본문 글꼴의 글자 지원 여부와 PDF 텍스트 문자 수의 왕복 검사
- 본문 글꼴 포함, 자산 그림의 미포함 글꼴 기록
- 단의 좌우·상하 경계를 넘는 출력 요소
- 실제 PDF 면 수·크기, 각 단 한 문제, 홀수 마지막 문항 처리
- 최종 PDF 해시와 시각 검수 기록·미리보기의 일치

수식은 벡터 경로이므로 문자 왕복 검사는 생성한 일반 텍스트에 적용됩니다. 수식은 입력 TeX와 렌더링 횟수를 비교하며, 의미적 전사 정확성은 원문 대조로 확인합니다. 그림 자산의 텍스트는 생성 본문과 분리해 취급합니다.

## 자동 검사만으로 보증하지 않는 내용

- 번역 의미, 잘못 읽은 원문 수식, AI가 원문에 없는 문항을 작성했는지 여부
- 원문에 있던 오탈자의 정오
- 모든 글리프의 실제 잉크 경계, 모든 종류의 문장부호 줄바꿈, 그림 안의 세부 정보
- 공식 평가원 서체·수식 엔진과의 픽셀 동일성

그래서 원문 대조와 최종 PNG 확인을 별도의 완료 조건으로 둡니다. CI는 이 검수 절차가 작동하는지 시험하며 특정 새 시험지의 정확성을 승인하는 역할은 하지 않습니다.

## 로컬 검증 사례

초기 작업은 JAM 2025 MA의 한국어 번역 60문항(160개 선택지, 100점, 출력 30면)에 적용했던 조판 코드를 일반화한 것입니다. 공식 원문: https://jam2025.iitd.ac.in/jam2025/MA_QP.pdf

타인의 시험지 원본·전체 번역·추출 글꼴은 이 저장소의 예제로 포함하지 않습니다. 공개 시연은 자체 작성한 문항만 사용합니다. 이 저장소는 과거 대화나 특정 Windows 사용자 경로가 없어도 실행할 수 있습니다.
